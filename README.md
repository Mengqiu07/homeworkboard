# 作业看板 · 免费发布版 v1.1.0

适用于 Windows 64 位的桌面作业看板。下载 EXE 后双击即可使用，无需安装 Python。

## 下载与使用

1. 从本项目的 GitHub Releases 下载“作业看板-免费发布版.exe”，放在固定位置后运行。
2. 看板显示在主屏右侧，约占屏幕宽度的三分之一。打开其他软件时，看板留在桌面。
3. 在看板内使用“＋”添加作业、“通”发布通知、“⚙”打开设置、“◷”查看历史。
4. 右键系统托盘图标，选择“退出并取消开机自启”可完全退出；托盘图标可能在隐藏图标区域。

## 作业

- 可选学科：语文、数学、英语、物理、化学、历史、政治、地理、生物。
- 填写作业时可添加自定义学科。添加后会保存在本机，之后仍可直接选择。
- 同一学科可记录多项作业；点击具体作业可修改或删除，输入内容会自动保存。
- “卷子、练习册、校本、订正、见群”提示词可点击插入。
- 每项作业可设置上交日期或选择“不交”；默认日期为下一个工作日。
- 每天 00:00 切换当天作业；08:00 前显示当天待交作业，历史记录可继续查看。
- 可在面板内将作业保存为 PNG 图片。

## 通知 · v1.1.0 新增

点击“通”进入通知页，填写内容并选择显示结束的日期和时间，精确到分钟。发布后，通知固定显示在所有作业上方；到达设置的时间会自动消失。

可以同时发布多条通知，也可以在通知页提前删除。通知保存在本机，重启程序后仍按原定时间显示。

## 课堂辅助

- 在设置中填写自己的课程安排；课程选项会同步到相关设置。
- 可维护学生名单，并使用随机选人功能。
- 提供浮窗、习语显示和分贝仪，相关选项可在设置中调整。

## 本地数据

程序数据保存在 C:\homeworkboard-free。每日作业在 days 文件夹，自定义学科在 custom_subjects.json，通知在 notices.json。备份时可复制整个 homeworkboard-free 文件夹。

发布包只包含 EXE。班级名单和课程安排由使用者在自己的电脑上填写。
