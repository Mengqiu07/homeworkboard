# 作业看板（公开版）

适用于 Windows x64 的离线桌面作业清单，版本 1.0.0。

## 使用方法

1. 将发布包解压到固定文件夹，双击 `作业看板-公开版.exe`。无需安装 Python。
2. 看板位于主屏右侧，约占屏幕四分之一，普通软件窗口会覆盖它。
3. 底部三个按钮：**添加作业、设置、历史记录**。
4. 退出时，右键系统托盘清单图标，选择“退出并取消开机自启”。图标可能位于托盘 `^` 隐藏区域。

手动启动或从托盘返回桌面时，会最小化普通软件窗口以显示看板，可以从任务栏恢复这些窗口。开机自启只后台显示看板。面板 Alt+F4 不退出程序。

## 功能

- 学科：语文、数学、英语、物理、化学、历史、生物、政治、地理、班务。
- 输入自动保存；同科可添加多项，单击某项作业可修改或删除。
- 提示词按键：卷子、练习册、校本、订正、见群，点击插入光标处。
- 每项可选择上交日期或“不交”，默认下一个周一至周五的日期，不自动计算节假日。
- 每天凌晨 00:00 切换当天清单，历史保留；08:00 前显示当天待交提醒，08:00 起隐藏。
- 历史页和托盘菜单可导出 PNG；主面板没有保存图片按钮。
- 设置中可查看版本及作者链接。
- 普通运行启用当前用户的开机自启；从托盘正常退出后取消自启，系统关机保留自启。

公开版没有课表、课程状态、练习倒计时、等级班号或数学 A/B。

## 数据

数据目录：`%LOCALAPPDATA%\HomeworkBoardPublic`。

每日作业位于 `days` 子目录，异常日志为 `error.log`。备份时复制整个数据目录即可。程序不会自动导入其他版本的数据。

无需账号和网络连接，不含二维码、在线分享或遥测；点击作者链接时会调用默认浏览器访问 GitHub。不要将个人作业数据或日志上传到公开仓库。
